SOAP
kliens

A SOAP kliens a Spring Boot alkalmazás azon modulja, amely a Magyar Nemzeti Bank WSDL-leírója alapján a jaxws pluginnal legenerált Java osztályok segítségével XML-alapú SOAP üzeneteken keresztül kommunikál az MNB távoli webszolgáltatásával. A kliens átveszi a webes űrlapon kiválasztott devizát, valamint a kezdő- és záródátumot, majd ezekkel a paraméterekkel lekérdezi a hivatalos középárfolyamokat a szolgáltatótól. Végül feldolgozza a visszakapott XML-választ, hogy az adatokat kiírassa az oldalra és egy Chart.js grafikonon is megjelenítse.
