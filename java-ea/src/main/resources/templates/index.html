Az alkalmazás bemutatása

Az alkalmazás képes valós idejű és korábbi devizaárfolyamok lekérdezésére, grafikus megjelenítésére, valamint demo számlán történő devizakereskedési műveletek végrehajtására.

MNB SOAP Kliens

A Magyar Nemzeti Bank hivatalos WSDL alapú SOAP webszolgáltatásán keresztül lekérdezi a választott deviza adott időszakra vonatkozó középárfolyamait, majd táblázatosan és Chart.js grafikonon is ábrázolja azokat.

  • SOAP megnyitása

Oanda Forex Kliens

Az Oanda REST API segítségével megjeleníti a demo kereskedési számla adatait, aktuális és historikus instrumentum árakat kérdez le, valamint lehetővé teszi piaci pozíciók nyitását, listázását és zárását.
